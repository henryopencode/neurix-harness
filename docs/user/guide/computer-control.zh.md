# 浏览器与应用操作

[English](computer-control.md) | 中文

两个可选插件分别提供独立网页会话和可见的桌面输入。在 **插件 → 扩展工具** 中可以单独或同时启用。

## 选择插件

| 插件 | 平台 | 操作方式 | 画中画 |

|---|---|---|---|

| 浏览器操作 | Windows、macOS、Linux | 独立的隐藏 Playwright 浏览器；标签页与登录状态隔离 | 当前页面视口 |

| 应用操作 | macOS | 原生前台鼠标和键盘输入，也包括浏览器应用窗口 | 精确的应用窗口 |

浏览器会话隔离不是操作系统安全沙盒。应用操作会使用用户共享的桌面，并可通过原生控件操作已登录的现有浏览器窗口。

## 配置与审批

浏览器操作可选择本机已安装的 Chrome、Chromium 或 Edge，窗口始终隐藏。应用操作需要为启动 Harness 的应用授予 macOS 辅助功能权限；原生截图和画中画还需要屏幕与系统音频录制权限。

两个插件分别提供**每次操作前确认**开关，保存后立即作用于所有对话。`list` 和 `observe` 自动执行，其余每项操作都需要单次审批。审批不可用时阻止操作。一个插件的审批不会授权另一个插件。

文本模型请关闭**附带截图**，支持图像输入的模型可开启。画中画独立于模型截图设置。其他保存的设置在新对话中生效，高级设置只保留与该插件相关的超时。

## 测试浏览器操作

在新对话中输入：“使用 browser 打开 Example Domain，报告标题，新建第二个标签页，然后只关闭第二个标签页。”在过程详情中检查 `browser` 调用。第一个标签页应继续可用，日常浏览器窗口不应被移动或接收输入。

后续浏览器操作使用返回的标签页 ID 和观察到的定位器。工具在输入后返回新状态，应核对目标文本或页面变化。失败或取消前可能已有部分输入生效，继续前请先观察。

## 测试应用操作

新建一个空白文本编辑文档，然后输入：“使用 application 找到这个空白文本编辑窗口，输入 Harness control works 并读回，不要保存或关闭文档。”核对实际文档中的文本、系统指针向目标移动，以及应用画中画中的内容。

应用工具通过 `list` 和 `observe` 发现精确的原生窗口。原生点击使用最新的 `element_token` 作为 `ref`；像素输入需要同一窗口的最新截图。现有浏览器应用也使用这些原生操作，此工具不提供 Playwright 标签页操作。

应用操作会激活选中的窗口并使用系统鼠标和键盘。输入期间请避免操作桌面。**停止生成**会取消后续输入，但保留已经送达的变化。

## 查看画中画

每个启用的来源都有独立的预览按钮和画面。浏览器操作显示完整的当前视口，默认 1440×900 CSS 像素；视口之外的内容需要 Agent 滚动查看。调整画中画大小只缩放图片，不改变页面布局。应用操作显示选中的原生窗口。

拖动图片可移动窗口。拖动任一底角，或聚焦底角后使用方向键，可以保持比例调整大小。窗口会保持在视口内。悬停或聚焦图片可使用放大、还原、收起和关闭按钮。关闭或收起会停止截图，Agent 继续工作；可通过顶部按钮重新打开。

截图失败会保留上一帧并提供重试。预览图片仅用于显示，不会加入模型输入或会话事件。

## 恢复与结束

目标丢失时重新执行 `list` 和 `observe`。网页对话框需要显式调用 `dialog` 接受或取消。浏览器启动失败时应停止浏览器任务；请自行安装或选择支持的浏览器，再新建对话。Agent 不得借助其他应用或安装程序绕过失败。

页面加载慢或截图失败时保留已有标签页，复用返回的目标并以 `screenshot: false` 观察；反复失败应如实报告。`browser.reset` 仅关闭该会话的浏览器。`application.reset` 释放引用并保留用户应用。恢复的会话需要重新发现目标。

配置和限制参见[浏览器操作](../../../packages/experimental/browser-control/README.zh.md)、[应用操作](../../../packages/experimental/computer-control/README.zh.md)和[独立统一提供者](../../../packages/experimental/computer-use-unified/README.zh.md)。
