# 处理浏览器启动失败

[English](guide.md) | 中文

## 变更

所选浏览器无法启动时，电脑控制报告 `BROWSER_START_FAILED`。结果要求由用户修正，并指示 Agent 停止通过其他应用或安装程序自动恢复。宿主错误保留原始启动失败作为原因；模型可见消息不包含启动器的安装命令。

## 迁移

1. 如果集成按错误码处理结果，请在电脑工具失败处理中加入 `BROWSER_START_FAILED`。
2. 安装或解除所选浏览器的阻止，或在电脑控制中选择已安装的浏览器；保存后新建对话，再次尝试浏览器操作。
3. 检查下一次浏览器操作返回的状态，不要自动使用无关桌面应用或终端命令恢复。
