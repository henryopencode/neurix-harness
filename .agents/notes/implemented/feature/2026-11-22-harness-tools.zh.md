# Agent Note: 交互式 Harness 工具

Status: implemented

[English](2026-11-22-harness-tools.md) | 中文

## 问题

用户在 Neurix 中工作时，需要从当前工作区启动或续接交互式 Codex 或 Claude Code 会话，并查看相应工具是否安装在该执行环境。

## 决策

这些会话使用现有的用户终端。Web 组合包声明可用程序及其启动和续接参数。有打开的 Session 时，设置页通过该 Session 的子进程提供方检查可执行文件；否则使用 Host 的提供方。终端控制器在当前目录启动程序前，再次解析配置中的启动项。浏览器只选择程序和操作，不传可执行文件或参数。

此功能扩展了 [Web 侧栏终端](2026-09-09-web-sidebar-terminal.zh.md)，并遵循[用户终端权限](../architecture/2026-09-16-user-terminal-permissions.zh.md)。Neurix 管理标签页及 PTY 的生命周期；每个 CLI 管理自己的登录、审批及会话历史。

## 考虑过的替代方案

**通过 LLM 适配器或子智能体运行。** 委派任务或模型发起的轮次无法展示原生登录、会话选择器、完整交互界面及审批操作，也会让提示和会话历史多出一个负责方。

**自动管理安装。** 系统、包管理器和用户安装分别有自己的归属和更新规则。设置页链接供应商的安装流程，刷新检测不会改动已有安装。

## 后果

关闭标签页会结束其进程；重启 Host 不会重新启动该进程。续接使用供应商的会话选择器，Neurix 不会将终端记录作为模型上下文。浏览器回归测试通过实际交付的设置页、RPC 和 PTY 链路运行两个隔离的可执行测试替身。
