# @deepseek-ai/dsh-session-diagnostics

[English](README.md) | 中文

## 概述

在**设置 → 诊断与错误**中检查分组后的会话错误，不修改原始日志。按项目、类型、时间或文本筛选；展开错误组以查看各次记录并打开来源会话。普通列表使用已有索引，显式更新才会读取有数量上限的一批历史会话。下载本地 ZIP 前，可预览所选错误组或当前筛选结果。报告包含有长度上限、尽力脱敏的摘录，而非完整对话；分享前必须人工检查隐私。

<a id="use-this-package"></a>
## 使用本包

诊断设置页用于检查已记录的错误，不用于收集应用崩溃或验证是否恢复。

### 检查与导出

1. 打开**设置 → 诊断与错误**。默认范围为当前选中对话的工作目录；未选中对话时显示有权访问的全部项目。可切换到其他项目或全部项目，再按类型、时间和文本筛选。
2. 检查覆盖范围提示。**更新历史索引**会显式索引历史会话；更改筛选条件或重新加载列表不会打开冷日志。结果不完整时，会显示未索引会话数、省略记录次数和读取失败数。空结果仅表示可用索引中没有匹配错误，不表示所有操作均已成功。
3. 展开错误组，查看有长度上限的详情和事件／轮次引用。**打开来源会话**打开的是对话，不会定位到特定事件。若已记录的失败工具卡片提供诊断快捷入口，它会打开同一个设置分区并限定为该会话；匹配事件已索引时会展开对应错误组，但不会触发冷更新。合成的中断占位状态不提供该入口。具体原因与恢复情况仍未验证。
4. 选择错误组、导出单个已展开的错误组，或导出当前筛选出的全部错误组。检查完整 JSON 预览后，再选择**下载本地 ZIP**。浏览器将冻结的预览归档为 `diagnostics.md` 与 `diagnostics.json`；确认操作不会获取额外日志或上传报告。

预览与页面使用同一份已脱敏记录。Markdown 报告将诊断字段作为字面文本保留，包括其中的 Markdown、HTML 和代码围栏。报告不包含原始参数字段、完整对话、附件或成功命令的输出。常见凭据赋值、认证头、令牌模式、URL 查询值和用户主目录名称会被遮盖，但任意错误文本仍可能含有隐私。分享前请检查完整预览；自动遮盖不等于全面清除个人身份信息。

### 组合与配置

Web 应用组合包含本插件。自定义组合需将 `@deepseek-ai/dsh-session-diagnostics` 与会话存储、查询服务、投影注册表／缓存及远程访问服务一起挂载；浏览器入口依赖设置框架、生成的 Remote 方法、本地化、资源与工作区导航。[Web 应用补丁](../../bundle/web-app/cordis.patch.yml)负责随产品提供的组合配置。

所有上限均校验为整数。无效值会使插件配置被拒绝。

| 字段 | 默认值 | 接受范围 | 含义 |
|---|---|---|---|
| `maxOccurrencesPerSession` | `500` | `1`–`10000` | 每个会话保留最新的错误记录，并限制待完成工具调用引用的数量 |
| `maxDetailChars` | `2048` | `256`–`16384` | 每段详情摘录最多保留的字符数，包含截断标记 |
| `maxOccurrencesPerQuery` | `1000` | `1`–`10000` | 所有错误组总共返回的最大记录次数；保留最新的匹配记录 |
| `maxSessionsPerRefresh` | `100` | `1`–`1000` | 一次显式更新最多读取的历史会话数 |

更新优先处理缺少缓存值的会话，再优先处理较新的会话。项目或来源会话范围限制参与处理的会话；文本、类型和时间筛选限制返回记录，不限制历史索引工作。读取失败会保留可见的部分结果，而不是将未读历史视为空。错误组次数表示保留的匹配记录；省略次数还可能包含当前筛选范围之外的记录。

### 错误类型

分类依据结构化事件事实，而非猜测消息文本。类型、来源、代码和已脱敏摘要相同的记录归入同一组。

| 类型 | 记录依据 |
|---|---|
| 参数错误 | 带有 `INVALID_ARGS` 的工具失败 |
| 命令异常 | 前台 shell 非零退出、信号、超时或沙箱 runner 失败 |
| 权限拒绝 | 前台 shell 元数据报告沙箱拒绝 |
| 工具异常 | 其他错误工具结果，包括没有专门结构化代码的校验失败 |
| 轮次异常 | 轮次以错误原因结束 |

预期的工具中止、调用方中止的 shell 结果和用户停止的 shell 结果均被排除。非零 shell 退出仍是普通工具结果；即使没有 `isError`，结构化 shell 元数据也会使其出现在此处。

## 理解实现

<details>
<summary>实现细节——点击展开</summary>

注册的 `diagnostics` 投影以确定性方式从已提交的工具结果、嵌套 PTC 分派和错误轮次结束事件派生已脱敏记录。其 wire 值使用 `summary: false`，因此普通会话摘要不携带错误账本。继承的 fork 前缀不参与统计，避免重复计入相同错误。原始会话事件仍为真源；检查与导出不会追加展示事件。

`list` 仅读取实时投影快照或历史缓存快照。缺失值会计入未索引数量，不会隐式冷读。`refresh` 显式读取有权访问的历史日志，并驱动已注册的缓存归约。两种操作均逐个会话检查远程访问权限，包括在等待历史读取后重新检查。

保留数量与摘录长度上限参与检查点校验。保留内存随记录上限乘以文本上限增长，另加有数量上限的待完成调用引用。记录一次错误最多复制已保留的记录数组；工具调用记账最多复制有上限的待完成引用。无关事件不会扫描对话文本。

| 源码 | 职责 |
|---|---|
| [`src/index.ts`](src/index.ts) | 校验上限、鉴权后的仅缓存列表与显式更新 |
| [`src/projection.ts`](src/projection.ts) | 确定性保留、回放与继承前缀排除 |
| [`src/classify.ts`](src/classify.ts) | 索引与可选工具卡片快捷入口共享的结构化错误分类 |
| [`src/redact.ts`](src/redact.ts) | 摘录进入索引前进行有长度上限的尽力遮盖 |
| [`src/client/report.ts`](src/client/report.ts) | 冻结预览字符串与浏览器本地 ZIP 生成 |

</details>

<a id="model-experience"></a>
## 模型体验

### 诊断检查

#### 模型看到什么

不会直接看到任何内容。本包不注册工具、提示词区段或模型可见消息；`diagnostics` 投影与报告仅是面向用户的派生数据。

#### Token 影响

列出、更新、检查或导出诊断记录不会增加模型输入或结果 token。

#### KV Cache 影响

无。诊断记录不会改变模型请求或可复用前缀。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

索引覆盖范围描述的是受支持的已记录事实，并非所有错误的完整清单。LiveShare 访客不能列出这些本地诊断记录或触发历史索引；这两项操作仅限所有者。

- 缺少结构化 `shellOutcome` 元数据的历史 Bash 结果无法可靠提供命令结局。索引不会从渲染后的退出标记重建结局；后台启动确认和转入后台的命令也没有可分类的终止结局。
- 更新限制会话数量，不限制每份所选日志的大小。保留与响应上限会省略较旧记录，截断的摘录无法还原被省略的文本。
- 页面不收集通用运行时崩溃，不编辑处置状态，不诊断根因，也不依据后续类似调用推断恢复。来源导航仅打开会话，不支持精确跳转事件。
- 脱敏尽力而为。即使常见凭据和用户主目录名称已被遮盖，错误摘录及会话／事件引用仍可能敏感。
