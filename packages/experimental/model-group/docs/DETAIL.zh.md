# 模型群

在本页设置中选择要一起使用的模型，指定一个 leader，描述各模型擅长的任务，然后保存。已经打开的空白会话会自动同步成员；已开始使用的会话保留原成员。

## 发送任务

用自然语言描述任务。leader 会说明处理思路，选择合适的模型，并同时分配独立工作。你可以点名希望它使用的模型，也可以在 `@` 菜单中选择模型，让它直接回答。成员回复会在群中显示模型名称，公共任务板记录已分配的工作。

## 随时控制

任务运行时仍可补充指令。在成员行中停止某个模型，或停止当前轮次。成员复用已有工作区和文件工具，共同处理同一项目中的文件。

## 选择默认模式

新会话默认使用模型群。在本页修改后续会话的默认模式，或在会话中使用模式选择，只修改当前会话。
