# Model groups

Choose the models you want to use together and select one leader in the settings on this page. Describe what each model handles well, then save. Open blank conversations update automatically; conversations already in use retain their members.

## Send a task

Describe the task naturally. The leader explains its approach, chooses suitable models, and assigns independent work together. You can name the models you want it to use, or select a model from the `@` menu for a direct response. Member replies appear in the group with their model names, and the shared task board tracks assigned work.

## Keep control

Send additional instructions while work is running. Stop one member from its row, or stop the current round. Members use the existing workspace and file tools, so they work with the same project files.

## Choose the default mode

New conversations use model-group mode by default. Change the default on this page for future conversations, or use the mode selector in a conversation to change only that conversation.
